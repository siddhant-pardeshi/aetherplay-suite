The suite

Two apps. One workflow.

Space stages the game and manages sessions. Lab attaches to it and turns raw memory into something you can actually reason about.

The instrument

AetherPlay Lab

  • Exact and unknown-value search across int32 / int64 / float32 / float64
  • Progressive refinement — narrow thousands of candidates to one address
  • Previewed writes: see the change before it touches the game
  • Undo journal — every write is recorded and reversible
  • Freeze a value while the game keeps running
  • Save experiments and replay them later

The stage

AetherPlay Space

  • Game library with launch-and-return to your collection
  • Named spaces, each with fully separate save data
  • Session control — suspend, resume, and close cleanly
  • Paired connection: Lab attaches to whatever Space is running
  • Guest-first design: no accounts, nothing leaves the device

Playground

Crystal Sprint — meet the training game.

The suite ships with an original training game so you can learn the workflow on a target you own. Catch crystals with the orb — the panel on the right is what Lab would see, live.

Crystal Sprint

This is the web adaptation of the in-app training game

Move with mouse, touch, or arrow keys. Each catch costs energy — it refills on its own, so pace yourself. Missing a crystal does nothing fatal.
